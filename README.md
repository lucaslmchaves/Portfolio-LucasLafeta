### ✨ [Acesse a versão ao vivo aqui!](https://link-para-seu-deploy-na-vercel.com)

---

### 💡 O Conceito

A ideia é criar mais do que um simples site estático. Conforme você rola a página, você "caminha" por um quarto 2D, e os objetos nesse quarto (como um computador, um quadro na parede, uma estante de livros) servem como pontos de interação para revelar meus projetos, competências e informações de contato.

### ⚙️ Como Executar o Projeto Localmente

Se você quiser explorar o código ou rodar este projeto em sua máquina, siga os passos abaixo:

1.  **Clone o repositório:**
    ```bash
    git clone [https://github.com/lucaslmchaves/Portfolio-LucasLafeta.git](https://github.com/lucaslmchaves/Portfolio-LucasLafeta.git)
    ```

2.  **Navegue até o diretório do projeto:**
    ```bash
    cd Portfolio-LucasLafeta
    ```

3.  **Instale as dependências:**
    ```bash
    npm install
    ```

4.  **Inicie o servidor de desenvolvimento:**
    ```bash
    npm start
    ```

Agora, basta abrir [`http://localhost:3000`](http://localhost:3000) no seu navegador para ver o projeto.
